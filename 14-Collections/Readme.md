# Java Collections Framework

The Java Collections Framework provides classes and interfaces for storing and manipulating groups of objects.

## Topics Covered

- ArrayList
- LinkedList
- Vector
- Stack
- HashSet
- LinkedHashSet
- TreeSet
- HashMap
- LinkedHashMap
- TreeMap
- Iterator
- Comparable
- Comparator

## Importance for QA Automation

Collections are commonly used in:

- Selenium WebElement lists
- Test data handling
- API response processing
- Database results
- Dynamic test data
- Sorting and filtering test data
